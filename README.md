### Вопрос-ответная система для абитуриентов ВШЭ
Система отвечает на вопросы абитуриентов о ШВЭ, используя информацию с сайта www.hse.ru.\
Включает текстовый и голосовой интерфейсы для выполнения задач.

### Функционал программы
1. Поиск по сайту ВШЭ:
   1. генерация ответов на основе подхода RAG.
2. Текстовый интерфейс:
   1. ввод вопроса в текстовом формате;
   2. получение ответа в текстовом формате.
3. Голосовой интерфейс:
   1. ввод вопросов голосом;
   2. получение ответов голосом.
4. Агенты для выполнения задач:
   1. сравнение программ обучения.
5. Обработка неопределенных запросов:
   1. уведомление об отсутствии информации и рекомендации по уточнению запроса.

### Оцениваемые функции
1. Текстовый интерфейс:
   1. система корректно обрабатывает текстовые запросы и возвращает адекватные ответы.
2. Голосовой интерфейс:
   1. реализована работа с голосовым вводом и голосовым выводом.
3. RAG:
   1. корректная реализация поиска по заранее загруженным текстам.
4. Агенты:
   1. логический агент обрабатывает сложные запросы, требующие составления цепочек действий.
5. Обработка неопределенных запросов:
   1. система уведомляет пользователя о невозможности найти ответ и предлагает уточнить запрос.
6. Наличие интерфейса:
   1. реализован пользовательский интерфейс через Telegram-бот или Streamlit

### Содержание репозитория
- **src** -- директория с бэкэндом
- - **__init__.py** -- инициализирующий пакет файл
- **template** -- директория с шаблонами фронтэнда
- **main.py** -- выполняемый файл
- **requirements.txt**
- **.gitignot**

### Виртуальное окружение
Перед началом работы рекомендуется наладить виртуальное окружение.\
**Установим виртуальное окружение:**\
`python -m venv venv`\
Если все сделано правильно, у нас появилась директория "*venv*", предназначенная для хранения файлов окружения.\

**Активируем виртуальное окружение:**\
MacOs, Linux: `source venv./bin/activate`\
Windows: `venv\Scripts\activate`\

**Установим необходимые библиотеки в виртуальное окружение:**\
`pip install -r requirements.txt`\

В случае, если программы не заметила появление библиотек, перезайдем в среду разработки.\
**Виртуальное окружение настроено.**

### Поиск апи-ключа и его установка
Подменяем ip-адрес на зарубежный и переходим на сайт https://groq.com/.\
Проходим регистрацию, либо авторизумеся.\
Переходим к получению апи-ключа, нажав на кнопку "**FREE API KEY**"

### Создание файла для хранения апи-ключа и его заполнение
- Создаем файл "*.env*" в корне нашей директории.
- Открываем файл и записываем в нем `GROQ_API_KEY=`.
- Вставляем скопированный токен после `GROQ_API_KEY=` без пробелов.

В результате получится файл ".env", находящийся в корневой директории программы с примерным содержанием содержанием:\
```
GROQ_API_KEY=<Ваш_токен>
```
Будьте внимательны: **Апи-ключ имеет лимиты, установленные компанией Groq**. В случае если лимиты будут исчерпаны, следует заменить ключ в файле "*.env*" или подождать некоторое время.

### Запуск программы
Мы запустили виртуальное окружения, установили необходимые библиотеки, нашли токен и вставили его в созданный файл "*.env*"\
**Программа будет работать только в случае подмены ip-адреса на иностранный.**\
Запустим программу командой: `python main.py`\
По окончнию работы, программу можно выключить, к примеру введя в чат `stop=`
