### Вопрос-ответная система для абитуриентов ВШЭ
Система отвечает на вопросы абитуриентов о ШВЭ, используя информацию с сайта www.hse.ru.\
Включает текстовый и голосовой интерфейсы для выоплнения задач.

### Функционал программы
1. Поиск по сайту ВШЭ:
   1. геренация ответов на основе подхода RAG.
2. Текстовый интрефейс:
   1. ввод вопроса в текстовом формате;
   2. получение ответа в текстовом формате.
3. Голосовой интрефейс:
   1. ввод вопросов голосом;
   2. получение ответов голосом.
4. Агенты для выполнения задач:
   1. сравнение программ обучения.
5. Обработка неопределенных запросов:
   1. уведомление об отсутствии информации и рекомендации по уточнению запроса.

### Оцениваемые функции
1. Текстовый интерфейс:
   1. система корректно обрабатывает екстовые запросы и возвращает адекватные ответы.
2. Голосовой интерфейс:
   1. реализована работа с голосовым вводом и голосовым выводом.
3. RAG:
   1. корректная реализация поиска по заранее загруженным текстам.
4. Агенты:
   1. логический агент обрабатыват сложные зарпосы, требующие составления цепочек действий.
5. Обработка неопределенных запросов:
   1. система уведомляет пользователя о невозможности найти ответ и предлагает уточнить запрос.
6. Наличие интерфейса:
   1. реализован ползьвательский интерфейс через Telegram-бот или Streamlit

### Содержание репозитория
- **src** -- дериктория с бэкэндом
- - **__init__.py** -- инициализирующий пакет файл
- **template** -- дериктория с шалонами форнтэнда
- **main.py** -- выполняемый файл
